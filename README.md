# ימי הולדת עבריים

תוסף Chrome שקורא את ימי ההולדת של החברים שלך מדף ימי ההולדת בפייסבוק, ומתזכר אותך על ימי ההולדת **העבריים** שלהם.

## מה הוא עושה
- קורא את דף `facebook.com/events/birthdays`: שם, תאריך ושנת לידה כשהם גלויים.
- ממיר לתאריך עברי עם לוח השנה העברי המובנה בדפדפן (`Intl`). אין צורך בספריות חיצוניות.
- מקפיץ התראות Chrome ביום עצמו, ואפשר גם כמה ימים לפני.
- מציג רשימת חברים להשלמת שנת לידה, ומאפשר לסמן מי נולד אחרי השקיעה.
- מייצא קובץ `.ics` עם ימי ההולדת העבריים ל־10 השנים הבאות, לייבוא ל־Google Calendar או לאייפון.

## איך הסנכרון עובד
דף ימי ההולדת מציג תאריכים רק לשבוע הקרוב. לכן התוסף פותח את הדף בלשונית ברקע כל כמה ימים (ברירת המחדל: 3), ובמשך שנה אוסף את כל החברים. גם כשאתה נכנס לדף בעצמך, התוסף קורא אותו.

התוסף רק קורא טקסט מהדף. הוא לא לוחץ, לא גולל ולא כותב. כל הנתונים נשמרים מקומית (`chrome.storage.local`) ולא נשלחים לשום מקום.

## התקנה
1. פתח את `chrome://extensions` והפעל את מצב מפתח (Developer mode).
2. לחץ "טען פריט לא ארוז" (Load unpacked) ובחר את התיקייה הזו.
3. לחץ על אייקון התוסף ואז על "סנכרון עכשיו". כדי שזה יעבוד צריך להיות מחובר לפייסבוק.

## כללי ימי הולדת עבריים
אותם כללים כמו ב־Hebcal:
- מי שנולד באדר בשנה רגילה חוגג באדר ב׳ בשנה מעוברת.
- מי שנולד באדר א׳ או באדר ב׳ חוגג באדר בשנה רגילה.
- ל׳ בחשוון, ל׳ בכסלו ול׳ באדר א׳: בשנה שבה החודש קצר, יום ההולדת עובר ל־א׳ בחודש הבא.

## מגבלות
- קריאת הדף תלויה במבנה הדף של פייסבוק, והיא תישבר אם המבנה ישתנה.
- איסוף נתונים אוטומטי מפייסבוק מנוגד לתנאי השימוש שלה. התוסף מיועד לשימוש אישי, בתדירות נמוכה.
